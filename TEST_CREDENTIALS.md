## Important Notes

- **Login Required:** The app now enforces authentication. You must log in to access any features.
- **No Auto-Login:** Auto-login has been removed for security. Users must manually sign in.
- **Logout:** Available from the profile screen (bottom-right icon in navigation bar)
- **Data Persistence:** All data is stored in Supabase and persists across sessions
